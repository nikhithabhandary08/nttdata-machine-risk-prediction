# NTT DATA Machine Risk Prediction

A web application for dynamic machine data management and local machine risk prediction.

## Project Overview

This application allows users to:

- Configure machine fields dynamically
- Create, view, edit, and delete machine records
- Store machine data in a database
- Predict machine risk using a local Python Machine Learning model
- View the prediction result through a web interface

## Technology Stack

- Frontend: React
- Backend: FastAPI
- Database: SQLite
- Machine Learning: Python and scikit-learn

## Risk Levels

- Low Risk
- Medium Risk
- High Risk
